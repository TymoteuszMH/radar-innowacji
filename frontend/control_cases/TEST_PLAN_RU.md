# Ручная проверка Online Discovery v0.5

1. Сделайте копию папки v0.4 и экспорт `workspace.json`.
2. Распакуйте v0.5 поверх копии, не заменяя `data/workspace.json`.
3. Откройте `app/index.html` в Chrome или Edge. Перейдите в **Szukaj w internecie**.
4. Выберите **NCBR — tylko lokalna próbka**, запрос `edukacja`. Ожидается две образовательные карточки с реальными URL. Запрос `czujnik` должен показать техническую карточку.
5. Выберите **OpenAlex — tylko API na żywo**, запрос `adaptive learning`. Проверьте получение результатов, даты, организацию и прямой URL. В случае блокировки должны появиться сообщения об ошибке, а не поддельные результаты.
6. Выберите **oba źródła**, запрос `edukacja`. При успешном OpenAlex должны появиться разные явно помеченные виды результатов. При сбое — только NCBR и предупреждение.
7. У одной карточки NCBR нажмите **Sprawdź i dodaj do katalogu**, исправьте необходимые поля, сохраните. Убедитесь, что в карточке сохраняется ссылочный первоисточник, а в `workspace.json` — `source_url`, `source_provider`, `source_identifier`.
8. Проверьте `Wykrywanie w dokumentach` и **Uruchom 2 przykłady**: офлайн-движок должен работать без интернета.
9. Перезапустите приложение и убедитесь, что ранее сохранённые пользовательские данные не исчезли.

## Известные ограничения

- При запуске `file://` CORS OpenAlex может блокировать запросы; локальная NCBR-выборка работает независимо.
- Параметры API, тарифы, доступность и CORS могут измениться. Ключ API нельзя хранить в статической странице; для ключа потребуется защищённый посредник либо локальный сервис.
- NCBR — **не живой поиск**, только три проверенные страницы. Даты периода проекта не являются датами публикации страницы.
- Точное значение метрик качества не установлено: три реальные записи — контрольный набор, а не независимая оценка точности.
- Никаких персональных/секретных данных в запросах OpenAlex.
